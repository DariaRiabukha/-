Окружение (на чем тестируем):

Ответственный за тестирование: Рябуха Дарья Сергеевна

Тестируемый модуль: авторизация

Список проверок:

Позитивные сценарии :
1) Войти (Успешная авторизация с валидными данными)
2) Разные суффиксы почты (gmail, mail, yandex и др.)
